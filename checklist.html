3One decision only you can make Decision

Is Glimmerly "primarily directed at children"?

Play Console's content questionnaire asks this directly, and it changes which policies apply (Google's Families program restricts things like ad SDKs and certain APIs).

Recommendation: answer yes — the app is genuinely built for a first grader. This costs nothing here: Glimmerly already has zero ads, zero analytics, zero data collection, so it already satisfies the stricter Families requirements without any further changes.

Target age group: Ages 5–8 fits first-grade content best.

8Before you upload — back this up

The release keystore is irreplaceable

The keystore file and its passwords were sent to you separately. If Glimmerly is ever updated after this first release, the same keystore is needed to sign the update — Play Store rejects an update signed with a different key. Losing it means this app listing can never receive an update again under this same package.

Right now, before anything else: copy the keystore file and its password into a password manager or another safely backed-up location — not only on this computer.

9Submission steps, in order

  1. Create a Google Play Developer account

    One-time $25 registration at play.google.com/console, if not already done.

  2. Create the app

    App name "Glimmerly: Early Learning", default language English, category Education, declare it's free.

  3. Fill in the store listing

    Paste the short/full description from Section 4, upload the icon, feature graphic, and screenshots, and add the privacy policy link.

  4. Complete Content rating, Data safety, Ads, and Target audience

    Using the answers in Sections 3, 5, 6, and 7 above.

  5. Upload the release

    Create a production release (or start with an internal testing release to try it first) and upload app-release.aab. Accept Play App Signing when prompted — Google will re-sign the app for distribution using your uploaded key as the "upload key."

  6. Submit for review

    Google typically reviews new apps within a few days to about a week.
