# Glimmerly Privacy Policy

This repo hosts the public privacy policy page for **Glimmerly: Early
Learning**, published via GitHub Pages at:

https://rishikeshtadaka.github.io/Glimmerly-public/

It exists as a separate, standalone public repo specifically so the policy
has a stable public URL for the Google Play Store listing, without making
the app's own (private) source repository public.

The page itself is a single static file, `index.html` — no build step.
